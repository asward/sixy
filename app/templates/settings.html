Local engine (VPN)

Only ports that answer count as open. WireGuard never answers, so it can't be detected. Leave empty to skip UDP.
Behind a VPN, "what's my IP" returns the VPN's IP. Either set Target below to your DDNS hostname, or point this at a URL outside the tunnel that returns your home IP as plain text.

Before every scan Sixy checks the IP its own traffic comes from. If that equals the target, it refuses to scan: you'd be scanning from inside your network (NAT hairpin) instead of from the internet.

1 · Google Cloud setup (one time, ~3 minutes)

In the Cloud Console, create a project and link billing (required for Cloud Run; usage stays inside the free tier — add a $1 budget alert to be safe). Then open Cloud Shell and paste:

PROJECT=your-project-id
gcloud config set project $PROJECT
gcloud services enable run.googleapis.com logging.googleapis.com
gcloud iam service-accounts create sixy-scanner --display-name="Sixy"
SA=sixy-scanner@$PROJECT.iam.gserviceaccount.com
for R in roles/run.developer roles/logging.viewer roles/logging.logWriter; do
  gcloud projects add-iam-policy-binding $PROJECT --member=serviceAccount:$SA --role=$R --condition=None -q >/dev/null
done
gcloud iam service-accounts add-iam-policy-binding $SA --member=serviceAccount:$SA --role=roles/iam.serviceAccountUser -q >/dev/null
gcloud iam service-accounts keys create sixy-key.json --iam-account=$SA
cloudshell download sixy-key.json

The key can only manage Cloud Run jobs and read logs in that one project. Revoke it anytime under IAM → Service accounts → sixy-scanner → Keys.
